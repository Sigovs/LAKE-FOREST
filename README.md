# Lake Forest Sports Cars / Mancuso — homepage prototype

Working prototype for the Mancuso family homepage (History as the main focus → the upcoming GT →
RPM Club → Instagram → contact). Not for publication.

- Current work: `sketches/` (latest scene build) and `docs/` (direction, scene sequences, client questions)
- Previous versions: `versions/v1`, `versions/d2`, `versions/sketches-2026-10-15-rejected`
- Web images: `assets/img/` — generated by `tools/prepare-images.py` from the client's source archive
  `lake photos/`, which is **not** in this repository (unconfirmed publishing rights). Copy it into the
  project root to regenerate images.
- Design system: Design DNA (`CLAUDE.md`, `BRIEF.md`)
- Run locally: `python3 -m http.server 8765` in the project root, then open `/sketches/…/`

Facts on the page are sourced (Fra Noi 2005, Ward's 2001, RPM Club / AM 560, the GT film). Open
questions are in `docs/client-questions.md`. Note: Lake Forest Sports Cars has been sold; the GT is
made by a new company whose name is pending.
