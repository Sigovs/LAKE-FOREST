# Mancuso / Lake Forest — homepage prototype

Working prototype for the Mancuso family homepage: History (the main focus) → the GT → RPM Club → Instagram → contact. Not for publication.

- **The page:** `index.html`, `styles.css`, `motion.js`, `micro.js`, `player.js`, `zoom.js`, `form.js` at the project root. Preview: https://sigovs.github.io/LAKE-FOREST/
- **Images:** `assets/img/` (web copies only). The client's source archive `lake photos/` and the working sources in `alex_images/` stay local and are not in the repository.
- **Docs:** `docs/client-questions.md` (open questions), `docs/final-package-references.md` (reference package), `docs/photo-inventory-2026-10-19.md` (which photos exist, by chapter).
- **Design system:** Design DNA (`CLAUDE.md`, `BRIEF.md`).
- **Run locally:** `python3 -m http.server 8765` in the project root, then open http://127.0.0.1:8765/
- **Older builds** (V1, D2, D3, sketches) were removed from the working tree on 20 Oct 2026; they are in git history under the tag `archive/before-cleanup-2026-10-20`.

Facts on the page are sourced (Fra Noi 2005, Ward's 2001, RPM Club / AM 560, the GT film). Lake Forest Sports Cars has been sold; the GT is made by a new company whose name is pending.
